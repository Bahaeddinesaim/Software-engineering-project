TelcoGuard AI
=============

API de prédiction du départ des clients télécom, conçue pour démontrer une chaîne
Data/ML reproductible et testée. L'équipe métier peut prioriser des actions de
fidélisation ; une estimation statistique ne prouve pas l'efficacité d'une action.

Projet SOENFO, MSc Informatique & Management, spécialisation Data, EPITA,
année 2026–2027. Auteur : SAIM Bahaeddine. Enseignante : Dr. Nour El Houda Ben Chaabene.
Travail académique de groupe ; aucun autre membre n'est déclaré.
